# AI Midas Polymarket Football Data — Jogos do Dia

## Descrição

Este repositório contém dados gratuitos sobre **jogos do dia na Polymarket**, organizados para análise de mercados preditivos de futebol.

A base reúne informação sobre competições, eventos, probabilidades implícitas, odds, volume, liquidez e spread para diferentes mercados ligados aos jogos.

O objetivo não é entregar palpite.  
É estruturar dados de mercado para quem quer analisar futebol como probabilidade, preço, risco e liquidez.

---

## Dados disponíveis

O ficheiro inclui dados atualizados por snapshot, permitindo observar como os mercados da Polymarket estão a precificar determinados jogos e eventos ao longo do tempo.

Estão disponíveis informações sobre:

- competição;
- evento;
- data de encerramento do mercado;
- probabilidades do moneyline;
- odds do moneyline;
- volume total;
- volume nas últimas 24 horas;
- liquidez;
- spread;
- mercados de empate;
- mercados de over/under 2.5;
- mercados de ambas marcam;
- URL do mercado na Polymarket.

## Description

This repository contains free data on today’s football matches on Polymarket, organized for football prediction market analysis.

The dataset brings together information on competitions, events, implied probabilities, odds, volume, liquidity, and spread across different markets linked to football matches.

The goal is not to provide betting picks.
It is to structure market data for those who want to analyze football through probability, price, risk, and liquidity.

## Available data

The file includes data updated by snapshot, making it possible to observe how Polymarket markets are pricing specific matches and events over time.

Available information includes:

competition;
event;
market end date;
moneyline probabilities;
moneyline odds;
total volume;
volume over the last 24 hours;
liquidity;
spread;
draw markets;
over/under 2.5 markets;
both teams to score markets;
Polymarket market URL.
